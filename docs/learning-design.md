# 學習設計說明（給爸媽和 Grok）

更新：2026-11-13（第六版：加上國語第七課「到此『藝』遊」，加入 review/bank.js 複習題庫）。這份說明整理了網站接下來的設計方向，以及「今天的複習」的運作方式。之後不管是 Claude 還是 Grok 改網站，都請先看這份。

## 1. 起點：孩子提出的要求

瑄瑄希望網站「更好玩」，而且要有**主動回想**和**間隔練習**。她很喜歡社會科的「臺灣縣市拼圖」（`social/map-life/` 的生活家挑戰站），覺得有趣，也真的記得住。

拼圖有效的原因有四個：

- **沒有選項**。她必須從腦中找出「新竹在哪裡」，這就是主動回想。
- **要親手放上去**。拖曳、擺放的動作讓記憶更具體。
- **馬上知道對錯**。放錯會搖一下，放對會跳出一張小卡。
- **可以跟自己比**。有最快紀錄，還有第二階段「找找看」再考一次。

## 2. 國語、數學、自然的現況

**做得好的地方**

- 內容已經對照孩子的課本。
- 每一頁都有「學習 → 練習 → 挑戰 → 紀錄」的結構。
- 數學有「常錯的地方」和「最近錯的題目」。
- 動手操作的部分很好，例如量角實驗室、釘板、拉三角形頂點、撕日曆、構造放大鏡。

**主要問題**

1. **選擇題太多**。選擇題考的是「認得」，不是「想得出來」，可以靠刪去法猜對，記憶效果比較弱。
2. **沒有間隔**。每一頁都是玩一次、拿到章就結束，沒有理由隔幾天再回來。錯題大挑戰的「連續答對 2 次」算是精熟，但同一天連答兩次就過了，不算間隔。
3. **沒有交錯**。每頁只練一個單元、一種題型。考卷上的題目是混在一起的，「先判斷要用什麼方法」的能力只有混著練才練得到。
4. **自然的文字偏多**。偵探筆記要讀的東西比動手的多。

## 3. 讓記得更牢的三個機制

| 機制 | 意思 | 網站怎麼做 |
|---|---|---|
| 主動回想 | 先從腦中把答案想出來，再看答案 | 國語看注音寫國字，寫完才看答案；數學自己算、自己填；自然先想好，再看選項 |
| 間隔練習 | 隔一段時間再考，而且越記得就隔越久 | 「今天的複習」的盒子制度：答對隔 2、4、7、14、30 天，答錯隔天再來 |
| 交錯練習 | 不同科目、不同題型混在一起練 | 每天的複習卡由國語、數學、自然輪流出，同一科盡量不連續 |

另外的配套：

- **錯了馬上給正確答案和理由**；數學會依錯的答案說出「可能錯在哪」。
- **答錯的卡當天最後再練一次**，數學會換數字。
- **答錯的卡變成小怪物**，下次複習答對就打倒牠，讓間隔練習看得見。

## 3-1. 參考：「時空守護者」

「時空守護者」（edu.liaison.tw）是雷森科技做的國中全科複習遊戲。下面這些做法值得學：

| 它的做法 | 我們怎麼用 |
|---|---|
| 答錯的題目變成地圖上的怪物，隔幾天換一組數字回來 | ✅ 已做：答錯的卡變成小怪物，下次複習答對就打倒 |
| 依錯的答案指出可能錯在哪（例如「移項忘了變號就會得到這個數」） | ✅ 已做：數學每種題型都有常見錯誤判斷 |
| 「謊言巨獸」：看別人的算式，點出第一個錯的那一步 | ✅ 已做：找錯小偵探（數學步驟、國語改錯字、自然跟課本不一樣的地方） |
| 答錯要等 4 秒才能繼續；有草稿紙；自己做的數字鍵盤 | ✅ 已做：自動改的題目答錯等 3 秒；草稿紙；數字鍵盤 |
| 答案就是動作：算出的數字就是砲火落點，算錯就照錯的方向打歪；選錯會演出「如果這樣會怎樣」 | ✅ 已做：數學的角度、公里、除法、大數定位板、數列、補 0 快算都會把答案演出來；自然的植物分類和月相選錯時，畫出「如果是你選的那個會怎樣」 |
| 家長進度連結（完成章節、答對率、每天玩幾關）；家長設定獎勵、孩子用金幣兌換 | ✅ 已做：學習紀錄頁（review/#parent）；爸媽設定的小獎勵，孩子用星星換，兌換要輸入家長密碼 |
| 課本單元對照表：學校教到哪一課，就玩哪一關 | 部分做到：複習設定可以關掉還沒教的單元 |
| 每完成一段主線，那一科的小鎮就多蓋好一樣 | 類似：記憶樹 |

**不照搬的**：抽卡（隨機獎勵容易讓小學生為了抽卡而玩）、扣愛心的壓力、登入和付費、大型世界地圖和長劇情。

## 4. 讓它更好玩的設計（依優先順序）

1. **今天的複習**：已完成，見第 5 節。包含小怪物、數學錯在哪、找錯小偵探。
2. **「放到對的位置」玩法**：把縣市拼圖的形式用到其他科。
   - 國語：把部首和部件拖在一起拼成生字；把詞卡排成句子（句型積木）。
   - 自然：把生物拖到池塘剖面上正確的位置；把背鰭、尾鰭、鰓蓋等標籤拖到魚身上（課本第 67 頁）；月相依農曆排順序。
   - 數學：把數字卡拖進定位板；把三角形拖進「銳角、直角、鈍角」三個籃子。
3. **考考爸媽**：孩子拿平板看答案，換爸媽作答、她來改。要出題，自己得先弄懂，這也是很好的複習，還能親子一起玩。
4. **其他原則**
   - **跟自己比**：最快紀錄、連續天數。休息一天不會斷，避免變成壓力。
   - **收集和成長**：記憶樹上，學過的卡是小綠芽，記牢了變成彩色葉子。忘了不會扣東西，用成長代替懲罰。
   - **先猜再學**：新課開始前先問一題，例如「布袋蓮壓進水裡放開會怎樣？」，猜錯沒關係。先猜過，再學答案會記得更牢。
   - **難度剛好**：答對率大約八成最有動力，太簡單會無聊，太難會放棄。
   - **短、有終點**：每次 5 到 10 分鐘，畫面清楚寫「今天完成了」。
   - **讓她自己選**：先玩哪一科、用什麼角色，讓她決定。
   - **要避免**：答錯扣分、太長的練習、太多跟學習無關的獎勵。

## 5. 「今天的複習」怎麼運作

**檔案**

- `review/index.html`：複習頁，包含今天的計畫、作答、記憶樹、各科進度和給爸媽的設定。
- `review/srs.js`：排程，管盒子、到期日、每天的量、交錯順序和連續天數。
- `review/bank.js`：題庫，包含科目、單元、卡片和數學出題程式。
- 首頁入口：`index.html` 裡 `<!-- 今天的複習 START -->` 到 `END` 的區塊，加上最下面讀取 `review/` 的程式。

**規則**

- 每張卡放在 1～6 號盒子。答對往後一盒，下次分別隔 1、2、4、7、14、30 天出現。答錯回到 1 號盒，隔天再來，當天最後也會再練一次。
- 新卡第一次就答對（表示上課已經學會），直接放 3 號盒，4 天後再考。
- 4 號盒以上（隔 7 天以上還記得）算「記牢了」。
- 每天先排到期的舊卡（最久沒複習的先），再補新卡。預設每天最多 8 張新卡，每次最多 20 張，大約 8 分鐘；爸媽可以在設定裡調整。
- 國語、數學、自然交錯出題。
- 連續天數：中間休息一天不會斷。
- **小怪物**：答錯（或想不起來）的卡會變成小怪物。複習頁有「👾 小怪物」區，顯示每隻哪一天出現；作答時會跳出「小怪物來了」，答對就打倒，並記錄打倒的總數。首頁入口會顯示今天有幾隻在等她。當天的「再試一次」答對，只會讓小怪物變弱，明天再答對才打倒，這樣才有間隔。
- **答錯停 3 秒**：自動改的題目（數學、自然、找錯）答錯時，要等 3 秒才能按下一張，先看解說，也避免亂猜。國語是自己對答案，不用等。
- **答案變成動作**：數學的角度、公里、除法題送出後，會把她的答案演出來，答對、答錯都演。
  - 角度：鐘面上的指針轉到她填的度數；或把她算的角拼到已知的角旁邊，看能不能剛好拼成直角、平角、周角，差多少或多多少用紅色標出來。
  - 公里：小車開到她填的距離，終點插旗，差多少公尺標出來。
  - 除法：糖果每盒裝除數那麼多顆，畫出她裝的盒數；剩下的糖果和一盒比長短，比一盒多就表示還能再裝一盒。最後用「除數 × 商 ＋ 餘數」驗算。
- **更多題型的動畫**：
  - 大數「數字代表多少」：定位板上，題目的數字和她的答案上下對齊，看得出那個數字差了一位。
  - 大數「寫成數字」：她寫的數字放進定位板，跟正確的逐格比，少補 0 的格子會變紅色。
  - 數列找規律：數線上一步一步跳，她填的那一步跳得不一樣就變紅色。
  - 補 0 快算：兩個數後面的 0 用顏色標出來，答案後面一顆一顆補上，看她少補還是多補。
- **如果這樣會怎樣（自然）**：選錯時才演。
  - 植物分類（蓮、睡蓮、布袋蓮、水蘊草、大萍）：左邊畫「如果是你選的那一種」會長怎樣，右邊畫課本說的那一種。
  - 月相：畫出你選的那一天的月亮，跟正確的月亮放在一起比。
- **星星和小獎勵**：
  - 星星只給努力，跟答對率無關：每天做完複習 ＋2，打倒一隻小怪物 ＋1。
  - 爸媽在「給爸媽」設定 4 位數家長密碼和獎勵清單（獎勵名稱、要幾顆星星）；可以先放建議的獎勵再改。之後要改獎勵，要先輸入密碼解鎖。
  - 孩子在複習頁的「🎁 星星和獎勵」看到自己有幾顆星、每個獎勵還差幾顆；星星夠了按「兌換」，要爸媽輸入密碼確認，才會扣星星。
  - 兌換紀錄在學習紀錄頁。家長密碼只存雜湊，是防小孩順手看到，不是真正的加密。
- **學習紀錄（給爸媽）**：在「給爸媽」按「看學習紀錄」，或直接打開 `review/#parent`。內容有：
  - 連續天數、總共複習幾張、答對率、記牢了幾張、小怪物。
  - 最近兩週每天有沒有做、做了幾張。
  - 各科、各單元的答對率，會標出最需要加強的單元。
  - 最常錯的卡：現在還是小怪物的排最前面。
  - 可以複製一段文字摘要，貼到 LINE。
  - 答對率只算每張卡當天的第一次作答。
- **數字鍵盤和草稿紙**：數學用畫面上的數字鍵盤，平板不會跳出系統鍵盤；有兩格答案時，點格子或按 Tab 換格。「草稿紙」可以直接在平板上算。
- 還沒教的單元，爸媽可以在設定裡先關掉。
- **還沒教（later）的單元**：數學第 7～10 單元（小數、整數四則計算、分數、統計圖）和社會第四、五單元（so7～so12）在設定裡標「還沒教」，**預設不出題**。學校教到時，爸媽在「給爸媽」的單元清單打勾，才會開始出題。

**三種卡**

| type | 用在 | 怎麼作答 | 怎麼改 |
|---|---|---|---|
| `write` | 國語生字（第 1～6 課，89 字） | 看課文句子裡的注音，在格子上寫國字 | 孩子自己對答案，按「寫對了／有一點錯／想不起來」。爸媽可以陪著看 |
| `num` | 數學（57 種題型） | 用數字鍵盤填數字，每次出不同的數字；小數題會多一個小數點鍵，分數題的格子排成分子、分母（帶分數多一格整數），統計圖題會在題目裡畫圖 | 自動改；答錯會說「可能錯在這裡」 |
| `pick` | 自然（48 張）、社會（217 張）、數學選擇題（14 種，例如三角形分類、比較大小、看圖選答案） | 先想好，按「我想好了」才出現選項 | 自動改 |
| `spot` | 找錯小偵探：數學 9 種（大數、乘法、平角、公里、小數加法、小數減法、四則計算、分數、統計圖）、國語改錯字 29 張、自然 13 張 | 點出第一個錯的地方 | 自動改 |

| `spell` | 英語拼字（24 個單字） | 看圖和中文，點字母拼出英文（會多 2 個不用的字母） | 自動改 |
| `order` | 英語排句子（24 句） | 點字把句子排好 | 自動改 |
| `pick`（聽音） | 英語聽音選意思（24 個單字） | 平板念出單字，再選中文意思 | 自動改 |
| `drag` | 放到對的位置：國語部件拼字 24 字、魚的身體構造、水生植物住哪裡、三角形分類籃子 | 拖到對的位置，或先點再點 | 自動改：沒放錯算答對、放錯 1 次算「有一點錯」、2 次以上算答錯 |

社會是 `pick`，題目照翰林課本。第一～三單元在 2026 年 11 月拿課本逐頁核對過：課本沒有的（季風、颱風、九降風、台地的高度、人口密度、7%／20% 的門檻等）都拿掉了，課本有但原本沒出的（農民曆、氣象觀測站、讀雨量氣溫圖、高齡社會 14%、活到老學到老等）補上。第四、五單元的題目直接寫在題庫。

目前共 584 張卡：國語 144、數學 85、自然 63、社會 217、英語 75。其中數學 57 張、社會 101 張屬於「還沒教」的單元，預設不出題。

**紀錄**：存在這台裝置瀏覽器的 `localStorage`，鍵名是 `studyReviewV1`，不會上傳。各課頁面原本的紀錄（星星、章）不受影響。

**備份**：「給爸媽」裡可以下載備份檔（`study-backup-日期.json`），裡面是整個網站在這台裝置的所有紀錄，包括各課的星星、錯題和複習；用備份檔或複製的文字可以還原，換裝置也能搬過去。上次備份的日期存在 `studyBackupAt`，超過 7 天沒備份，「給爸媽」的標題會提醒。

## 6. 給 Grok：要加題目或改複習功能時

**加卡片**：在 `review/bank.js` 加。

- 國語：生字資料是從各課頁面的 `CHARS` 整理出來的，欄位是 `l`（課次）、`c`、`zy`、`bs`、`tot`、`w`、`tx`。`tx` 必須是含那個字的課文句子。加新課時，同時在 `UNITS` 加 `cn7` 等單元。
- 數學：在 `GEN` 加一個出題函式，回傳 `{ q, fields:[{pre, unit}], ans:[整數...], ex, dg, viz }`。`viz` 可以不寫；寫了就會在送出後演出來，目前有 `clock`（鐘面）、`line`（拼角）、`road`（小車）、`div`（糖果裝盒）、`place`、`write`（定位板）、`seq`（數線）、`zero`（補 0）八種，畫法在 `review/index.html` 的 `vizHTML`、`playViz`、`vizMore`、`playMore`。`dg(答案陣列)` 依錯的答案回傳「可能錯在哪」的一句話，猜不出來就回空字串。選擇題回傳 `{ kind:'pick', q, opts, a, ex }`；找錯題回傳 `{ kind:'spot', block:true, q, parts:[每一步], bad:錯的那一步, fix, ex }`，錯的那一步之後要照錯的結果算下去，讓「第一個錯」只有一個。再到卡片清單加 `['單元', '函式名', '題型名稱']`。每種題型要用 node 跑 500 次，確認答案都是整數、沒有負數。
- 數學的分數和小數：`fields` 的每一格可以加 `fr:'w'|'n'|'d'`（帶分數的整數、分子、分母格，會排成分數的樣子）或 `den:數字`（分母固定，只填分子）；回傳 `dec:true` 會出現小數點鍵。答案用數值比對（容許 1e-9 的誤差），`ansText` 可以指定答案要怎麼顯示。小數一律先換成「幾個 0.01」的整數來算，再用 `fmtD` 顯示，避免電腦的小數誤差。統計圖用 `barSVG`、`lineSVG`、`pictoHTML` 畫在題目裡。
- **還沒教的單元**：在 `UNITS` 的單元加 `later: true`，那個單元的卡片會自動帶 `later`，預設不出題，爸媽打勾才開（存在 `st.set.on`）；一般單元預設出題，爸媽關掉存在 `st.set.off`。學校教到以後，可以把 `later` 拿掉。
- **頁面和題庫用同一套題目**：數學第 7～10 單元、社會第四、五單元的頁面會讀 `../../review/bank.js`。數學頁的練習直接呼叫題庫的 `GEN`，社會頁的練習從題庫的 `SO` 抽題，所以改題庫時，頁面的練習也會跟著變。
- 國語改錯字：`LOOK` 是 `[課次, 正確的字, 形近字, 課文句子]`，會把形近字放進句子裡讓她點。替換後不能變成另一個也說得通的詞，例如「紀錄／記錄」就不放。
- 社會：在 `SO` 加 `[單元, 題目, [選項...], 正確答案的位置, 說明]`。題目要是課本內容。
- 英語：單字在 `EN_W`（`[課次, 英文, 圖示, 中文, 例句]`），每個單字會自動變成拼字卡和聽音卡；句子在 `EN_O`（`[課次, 句子]`），用空白切成字。
- 拖曳：國語部件拼字在 `PARTS`（`[課次, 字, 'lr'左右或'tb'上下, 第一個部件, 第二個部件]`），部件一定要拆對；其他拖曳卡在 `GEN`（`fishParts`、`pondPlants`、`triSort`），回傳 `{ kind:'drag', mode:'board'/'baskets'/'char', slots, items, need, ex }`。
- 自然：選擇題用 `N('單元', 'id', '問題', '正確答案', ['錯的選項', '錯的選項'], '說明')`。要演「如果這樣會怎樣」，就在 `WI` 加一筆：植物分類用 `{ t:'plant', plant:'名稱' }`（選項要是四種植物名稱），月相用 `{ t:'moon', ang:{ 選項文字: 角度 } }`（0 看不到、90 右半亮、180 圓、270 左半亮）。找錯題用 `X('單元', 'id', ['一句話切成幾段'], 錯的那一段, '正確說法', '說明')`，其他段一定要跟課本一樣。

**規則**

- **卡片 id 不能改、不能重複**。孩子的進度是用 id 記的。社會、自然選擇題的 id 是用「單元＋題目文字」算的，所以改題目文字或換單元，那張卡的進度會重新開始。
- **題目要對照課本**。課外補充不要放進複習題庫，題庫只放考試會考的。
- 不要改 `srs.js` 的排程規則和 `localStorage` 的鍵名（`studyReviewV1`、`studyBackupAt`）；真的要改，先跟爸媽討論。其他頁面新增紀錄時，也存在 `localStorage`，備份會自動包含。
- 首頁的「今天的複習」區塊不要動；改首頁其他地方沒問題。
- 改完要測：頁面沒有錯誤、390 寬不會超出畫面、整輪複習可以做完。

## 7. 課本用字規範

**自然**

- 植物分類用「挺水性、浮葉性、漂浮性、沉水性植物」。
- 用「蓮」，不用「荷花」；沉水性的例子用「水蘊草」。
- 課本沒有的生物（鴨子、水黽、龍蝨、金魚藻、茭白筍等）可以出現在遊戲裡，但要標「課外補充」。
- 月相名稱課本只標「朔、上弦月、望、下弦月」。
- 課本沒有「天然／人工水域」分類、沒有滴色素實驗、沒有外來種。

**國語**

- 生字的注音照課本生字格。
- 多音字要註明，例如「挑」：挑戰念 ㄊㄧㄠˇ，挑選、挑食念 ㄊㄧㄠ。

**數學（康軒）**

- 小數只到百分位，位名用「個位、十分位、百分位」；小數加減直式要對齊小數點。
- 四則計算：先算括號，再算乘除、後算加減，同一級由左往右算；除法都要整除。
- 分數只做同分母的加減和整數乘分數，答案保留原來的分母，不約分；假分數和帶分數要會互換。
- 統計圖照課本的畫法：圖名在圖的下方，縱軸名稱在上方、橫軸名稱在右邊，只在主要格線標數字，省略的範圍用「≈」。
- 除法照課本，有用「整十」當除數的題目；三角形的選項照課本的分類方式。

**社會（翰林）**

- 地形：只有山地「超過 1,000 公尺」、丘陵「不超過 1,000 公尺」有高度，台地課本只說「地勢平坦的高地」，不要加高度。課本每種地形只有一個例子：合歡山、石碇、大肚台地、埔里盆地、嘉南平原；其他地名要標「延伸」。不要說五種地形「由高到低」。
- 氣候：課本沒教季風、颱風、九降風。課本的例子是臺南（溫暖，盛產芒果）、新竹（十月到隔年二月北方乾冷的風，適合晒米粉）、墾丁（四季陽光普照，度假勝地）。觀測站量的是「氣溫、雨量、風向和風速」。
- 人口：出生、死亡、移入、移出，以及中壢、大稻埕、九份、內灣、員林、頭份、池上、竹北、水林，都是第三單元第 1 課。課本沒有人口密度和 7%、20% 的門檻，只有第 2 課的「高齡社會：65 歲以上人口占總人口 14% 以上」。用「青壯年」「人口分布稠密／稀疏」「增設公共托育、育嬰假」「長照中心、樂齡學堂、二度就業」。
- 交通路線：課本是「第一種／第二種」走法，到臺中後轉搭「南投客運」，不要寫國光客運、臺灣好行。
- 第四、五單元：課本沒有的節日和禮俗（重陽節、屈原的故事、矮靈祭、喪禮）不出題；傳統節慶只有清明節用國曆。
- 頁面上課本沒有的內容可以留，但要標「🔎 延伸」，不能標「📖 課本」。
