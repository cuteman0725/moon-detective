# 學習設計說明（給爸媽和 Grok）

更新：2026-11-05（第二版：加上小怪物、數學錯在哪、找錯小偵探）。這份說明整理了網站接下來的設計方向，以及「今天的複習」的運作方式。之後不管是 Claude 還是 Grok 改網站，都請先看這份。

## 1. 起點：孩子提出的要求

瑄瑄希望網站「更好玩」，而且要有**主動回想**和**間隔練習**。她很喜歡社會科的「臺灣縣市拼圖」（`social/map-life/` 的生活家挑戰站），覺得有趣，也真的記得住。

拼圖有效的原因有四個：

- **沒有選項**。她必須從腦中找出「新竹在哪裡」，這就是主動回想。
- **要親手放上去**。拖曳、擺放的動作讓記憶更具體。
- **馬上知道對錯**。放錯會搖一下，放對會跳出一張小卡。
- **可以跟自己比**。有最快紀錄，還有第二階段「找找看」再考一次。

## 2. 國語、數學、自然的現況

**做得好的地方**

- 內容已經對照孩子的課本。
- 每一頁都有「學習 → 練習 → 挑戰 → 紀錄」的結構。
- 數學有「常錯的地方」和「最近錯的題目」。
- 動手操作的部分很好，例如量角實驗室、釘板、拉三角形頂點、撕日曆、構造放大鏡。

**主要問題**

1. **選擇題太多**。選擇題考的是「認得」，不是「想得出來」，可以靠刪去法猜對，記憶效果比較弱。
2. **沒有間隔**。每一頁都是玩一次、拿到章就結束，沒有理由隔幾天再回來。錯題大挑戰的「連續答對 2 次」算是精熟，但同一天連答兩次就過了，不算間隔。
3. **沒有交錯**。每頁只練一個單元、一種題型。考卷上的題目是混在一起的，「先判斷要用什麼方法」的能力只有混著練才練得到。
4. **自然的文字偏多**。偵探筆記要讀的東西比動手的多。

## 3. 讓記得更牢的三個機制

| 機制 | 意思 | 網站怎麼做 |
|---|---|---|
| 主動回想 | 先從腦中把答案想出來，再看答案 | 國語看注音寫國字，寫完才看答案；數學自己算、自己填；自然先想好，再看選項 |
| 間隔練習 | 隔一段時間再考，而且越記得就隔越久 | 「今天的複習」的盒子制度：答對隔 2、4、7、14、30 天，答錯隔天再來 |
| 交錯練習 | 不同科目、不同題型混在一起練 | 每天的複習卡由國語、數學、自然輪流出，同一科盡量不連續 |

另外的配套：

- **錯了馬上給正確答案和理由**；數學會依錯的答案說出「可能錯在哪」。
- **答錯的卡當天最後再練一次**，數學會換數字。
- **答錯的卡變成小怪物**，下次複習答對就打倒牠，讓間隔練習看得見。

## 3-1. 參考：「時空守護者」

「時空守護者」（edu.liaison.tw）是雷森科技做的國中全科複習遊戲。下面這些做法值得學：

| 它的做法 | 我們怎麼用 |
|---|---|
| 答錯的題目變成地圖上的怪物，隔幾天換一組數字回來 | ✅ 已做：答錯的卡變成小怪物，下次複習答對就打倒 |
| 依錯的答案指出可能錯在哪（例如「移項忘了變號就會得到這個數」） | ✅ 已做：數學每種題型都有常見錯誤判斷 |
| 「謊言巨獸」：看別人的算式，點出第一個錯的那一步 | ✅ 已做：找錯小偵探（數學步驟、國語改錯字、自然跟課本不一樣的地方） |
| 答錯要等 4 秒才能繼續；有草稿紙；自己做的數字鍵盤 | ✅ 已做：自動改的題目答錯等 3 秒；草稿紙；數字鍵盤 |
| 答案就是動作：算出的數字就是砲火落點，算錯就照錯的方向打歪；選錯會演出「如果這樣會怎樣」 | 之後做：角度題讓指針轉到她填的度數、公里題讓小車開到她填的位置 |
| 家長進度連結（完成章節、答對率、每天玩幾關）；家長設定獎勵、孩子用金幣兌換 | 之後做：家長進度頁、爸媽設定的小獎勵 |
| 課本單元對照表：學校教到哪一課，就玩哪一關 | 部分做到：複習設定可以關掉還沒教的單元 |
| 每完成一段主線，那一科的小鎮就多蓋好一樣 | 類似：記憶樹 |

**不照搬的**：抽卡（隨機獎勵容易讓小學生為了抽卡而玩）、扣愛心的壓力、登入和付費、大型世界地圖和長劇情。

## 4. 讓它更好玩的設計（依優先順序）

1. **今天的複習**：已完成，見第 5 節。包含小怪物、數學錯在哪、找錯小偵探。
2. **「放到對的位置」玩法**：把縣市拼圖的形式用到其他科。
   - 國語：把部首和部件拖在一起拼成生字；把詞卡排成句子（句型積木）。
   - 自然：把生物拖到池塘剖面上正確的位置；把背鰭、尾鰭、鰓蓋等標籤拖到魚身上（課本第 67 頁）；月相依農曆排順序。
   - 數學：把數字卡拖進定位板；把三角形拖進「銳角、直角、鈍角」三個籃子。
3. **考考爸媽**：孩子拿平板看答案，換爸媽作答、她來改。要出題，自己得先弄懂，這也是很好的複習，還能親子一起玩。
4. **其他原則**
   - **跟自己比**：最快紀錄、連續天數。休息一天不會斷，避免變成壓力。
   - **收集和成長**：記憶樹上，學過的卡是小綠芽，記牢了變成彩色葉子。忘了不會扣東西，用成長代替懲罰。
   - **先猜再學**：新課開始前先問一題，例如「布袋蓮壓進水裡放開會怎樣？」，猜錯沒關係。先猜過，再學答案會記得更牢。
   - **難度剛好**：答對率大約八成最有動力，太簡單會無聊，太難會放棄。
   - **短、有終點**：每次 5 到 10 分鐘，畫面清楚寫「今天完成了」。
   - **讓她自己選**：先玩哪一科、用什麼角色，讓她決定。
   - **要避免**：答錯扣分、太長的練習、太多跟學習無關的獎勵。

## 5. 「今天的複習」怎麼運作

**檔案**

- `review/index.html`：複習頁，包含今天的計畫、作答、記憶樹、各科進度和給爸媽的設定。
- `review/srs.js`：排程，管盒子、到期日、每天的量、交錯順序和連續天數。
- `review/bank.js`：題庫，包含科目、單元、卡片和數學出題程式。
- 首頁入口：`index.html` 裡 `<!-- 今天的複習 START -->` 到 `END` 的區塊，加上最下面讀取 `review/` 的程式。

**規則**

- 每張卡放在 1～6 號盒子。答對往後一盒，下次分別隔 1、2、4、7、14、30 天出現。答錯回到 1 號盒，隔天再來，當天最後也會再練一次。
- 新卡第一次就答對（表示上課已經學會），直接放 3 號盒，4 天後再考。
- 4 號盒以上（隔 7 天以上還記得）算「記牢了」。
- 每天先排到期的舊卡（最久沒複習的先），再補新卡。預設每天最多 8 張新卡，每次最多 20 張，大約 8 分鐘；爸媽可以在設定裡調整。
- 國語、數學、自然交錯出題。
- 連續天數：中間休息一天不會斷。
- **小怪物**：答錯（或想不起來）的卡會變成小怪物。複習頁有「👾 小怪物」區，顯示每隻哪一天出現；作答時會跳出「小怪物來了」，答對就打倒，並記錄打倒的總數。首頁入口會顯示今天有幾隻在等她。當天的「再試一次」答對，只會讓小怪物變弱，明天再答對才打倒，這樣才有間隔。
- **答錯停 3 秒**：自動改的題目（數學、自然、找錯）答錯時，要等 3 秒才能按下一張，先看解說，也避免亂猜。國語是自己對答案，不用等。
- **數字鍵盤和草稿紙**：數學用畫面上的數字鍵盤，平板不會跳出系統鍵盤；有兩格答案時，點格子或按 Tab 換格。「草稿紙」可以直接在平板上算。
- 還沒教的單元，爸媽可以在設定裡先關掉。

**三種卡**

| type | 用在 | 怎麼作答 | 怎麼改 |
|---|---|---|---|
| `write` | 國語生字（第 1～6 課，89 字） | 看課文句子裡的注音，在格子上寫國字 | 孩子自己對答案，按「寫對了／有一點錯／想不起來」。爸媽可以陪著看 |
| `num` | 數學（13 種題型） | 用數字鍵盤填數字，每次出不同的數字 | 自動改；答錯會說「可能錯在這裡」 |
| `pick` | 自然（48 張）、三角形分類（2 種） | 先想好，按「我想好了」才出現選項 | 自動改 |
| `spot` | 找錯小偵探：數學 4 種（大數、乘法、平角、公里）、國語改錯字 29 張、自然 13 張 | 點出第一個錯的地方 | 自動改 |

目前共 198 張卡：國語 118、數學 19、自然 61。

**紀錄**：存在這台裝置瀏覽器的 `localStorage`，鍵名是 `studyReviewV1`，不會上傳；換一台裝置要重新開始。各課頁面原本的紀錄（星星、章）不受影響。

## 6. 給 Grok：要加題目或改複習功能時

**加卡片**：在 `review/bank.js` 加。

- 國語：生字資料是從各課頁面的 `CHARS` 整理出來的，欄位是 `l`（課次）、`c`、`zy`、`bs`、`tot`、`w`、`tx`。`tx` 必須是含那個字的課文句子。加新課時，同時在 `UNITS` 加 `cn7` 等單元。
- 數學：在 `GEN` 加一個出題函式，回傳 `{ q, fields:[{pre, unit}], ans:[整數...], ex, dg }`。`dg(答案陣列)` 依錯的答案回傳「可能錯在哪」的一句話，猜不出來就回空字串。選擇題回傳 `{ kind:'pick', q, opts, a, ex }`；找錯題回傳 `{ kind:'spot', block:true, q, parts:[每一步], bad:錯的那一步, fix, ex }`，錯的那一步之後要照錯的結果算下去，讓「第一個錯」只有一個。再到卡片清單加 `['單元', '函式名', '題型名稱']`。每種題型要用 node 跑 500 次，確認答案都是整數、沒有負數。
- 國語改錯字：`LOOK` 是 `[課次, 正確的字, 形近字, 課文句子]`，會把形近字放進句子裡讓她點。替換後不能變成另一個也說得通的詞，例如「紀錄／記錄」就不放。
- 自然：選擇題用 `N('單元', 'id', '問題', '正確答案', ['錯的選項', '錯的選項'], '說明')`；找錯題用 `X('單元', 'id', ['一句話切成幾段'], 錯的那一段, '正確說法', '說明')`，其他段一定要跟課本一樣。

**規則**

- **卡片 id 不能改、不能重複**。孩子的進度是用 id 記的。
- **題目要對照課本**。課外補充不要放進複習題庫，題庫只放考試會考的。
- 不要改 `srs.js` 的排程規則和 `localStorage` 的鍵名；真的要改，先跟爸媽討論。
- 首頁的「今天的複習」區塊不要動；改首頁其他地方沒問題。
- 改完要測：頁面沒有錯誤、390 寬不會超出畫面、整輪複習可以做完。

## 7. 課本用字規範

**自然**

- 植物分類用「挺水性、浮葉性、漂浮性、沉水性植物」。
- 用「蓮」，不用「荷花」；沉水性的例子用「水蘊草」。
- 課本沒有的生物（鴨子、水黽、龍蝨、金魚藻、茭白筍等）可以出現在遊戲裡，但要標「課外補充」。
- 月相名稱課本只標「朔、上弦月、望、下弦月」。
- 課本沒有「天然／人工水域」分類、沒有滴色素實驗、沒有外來種。

**國語**

- 生字的注音照課本生字格。
- 多音字要註明，例如「挑」：挑戰念 ㄊㄧㄠˇ，挑選、挑食念 ㄊㄧㄠ。
