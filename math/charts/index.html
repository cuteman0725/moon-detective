圖示統計圖用圖案表示數量。一定要先看說明框：大圖案、小圖案各代表多少（小圖案不一定是一半！）。

🔍 讀長條圖的 4 個重點

  1. 標題（在圖的下面）：這張圖在說什麼
  2. 橫軸表示什麼
  3. 縱軸表示什麼，單位是什麼
  4. 表示數量的格線中，每一格表示多少（不一定是 1！）

長條停在兩條格線的正中間時，要讀中間的數，例如 44 和 46 中間是 45。

✏️ 我來畫長條圖

  1. 寫上長條圖的標題。
  2. 寫上橫軸表示什麼及各種類名稱。
  3. 寫上縱軸表示什麼及單位。
  4. 縱軸標示刻度代表的數量。
  5. 分別依據統計的項目和數量，畫出長條來表示。

📈 折線圖說故事

折線圖的資料有時間的先後順序，比較容易看出變化。連線往上是上升，往下是下降，平平的是不變。

📄 ≈ 把不必要的部分省略

從 0 開始畫，線幾乎是平的，看不清楚變化。把下面不必要的部分像紙一樣摺起來，用 ≈ 省略，就看得清楚了。

⚠️ 有 ≈ 的時候，要從標好的刻度開始讀，不能從 0 開始數格子。

🎨 兩組資料畫在一張圖

先看色塊說明：哪個顏色代表哪一組。點按鈕可以只看其中一組。
