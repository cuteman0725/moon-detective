## 課程特色

### 📚 學習內容

每一課包含:

1. **課文** 📖
   - 完整課文內容
   - 課文導讀和賞析
   
2. **生字** 🔤
   - 生字卡片 (注音、部首、筆畫)
   - 造詞練習
   - 課文例句
   - 描寫板練習
   
3. **語詞** 💬
   - 重點語詞
   - 例句說明
   - 語詞練習
   
4. **句型** 📝
   - 句型說明
   - 造句練習
   - 應用測驗
   
5. **挑戰** 🎯
   - 綜合測驗 (10 題)
   - 即時回饋
   - 分數統計
   
6. **紀錄** ⭐
   - 學習進度追蹤
   - 最佳分數紀錄
   - 徽章收集

### ✨ 互動功能

- 📱 **響應式設計**: 支援手機、平板、電腦
- 💾 **自動儲存**: 學習進度自動保存
- 🎨 **描寫板**: Canvas 手寫生字練習
- ⭐ **星星獎勵**: 答對題目獲得星星
- 🏆 **徽章系統**: 達成特定條件獲得徽章
- 📊 **學習統計**: 追蹤學習時間和成績

### 🎯 設計理念

依照 `docs/learning-design.md` 設計:

1. **漸進式學習**: 從閱讀 → 認字 → 造詞 → 造句 → 測驗
2. **即時回饋**: 答題後立即顯示說明
3. **成就感**: 星星、徽章、最佳紀錄
4. **自主學習**: 可重複練習,不限次數
5. **行動優先**: 在 390px 寬的手機也能順暢使用

## 複習系統

所有生字會自動加入 [`/review/`](../review/) 的「今天的複習」系統:

- 🗓️ **間隔重複**: 依照記憶曲線排程 (1, 2, 4, 7, 14, 30 天)
- 🔀 **交錯複習**: 混合不同課程的題目
- 📈 **進度追蹤**: 記錄每張卡片的學習進度
- ⭐ **星星獎勵**: 連續答對升級到下一盒

## 技術說明

- **純前端**: HTML + CSS + JavaScript,無需伺服器
- **無相依**: 不依賴外部函式庫
- **離線可用**: 開啟後可離線使用
- **輕量化**: 每頁約 50-100 KB
- **相容性**: 支援現代瀏覽器 (Chrome, Safari, Firefox, Edge)
